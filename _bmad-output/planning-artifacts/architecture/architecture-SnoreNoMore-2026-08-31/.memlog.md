- (decision) AD-1 [ADOPTED] Single-file, zero-build, CDN-ESM delivery. Binds all. Prevents adding a bundler/npm/build step or split that needs compilation. Rule: whole app ships as one static index.html + manifest.json, every dependency loaded from CDN (ESM import or script tag), must run when served statically with no npm install.
- (decision) AD-2 [ADOPTED] On-device-only, zero egress. Binds all data + CAP-6. Prevents any feature adding fetch/XHR/sendBeacon/WebSocket that carries audio or night data. Rule: no network call may carry audio or night data off-device; the only permitted network is the initial CDN asset fetch.
- (decision) AD-3 Canonical night-record contract + authoritative formulas. Binds CAP-2/3/4/5. Prevents real, simulate, persistence and views drifting on record shape or metric math. Rule: every night (real or simulated) is the one documented record shape and derives timeInBed/timeSnoring/snorePct/snoreScore ONLY via finalizeNight->computeMetrics; views read the persisted derived fields and never recompute.
- (decision) AD-4 Segment is the universal intermediate representation; real and simulate converge on it. Binds CAP-2. Prevents the demo path weakening the real mic path or the two emitting incompatible shapes. Rule: capture (samples->ampToLevel->samplesToSegments) and synthesis (synthSegments) both emit segments {tStart,tEnd,level,peak}; tStart/tEnd are 0-based ms from capture start, level in LEVELS, peak in [0,1]; all downstream is source-agnostic except the simulated flag.
- (decision) AD-5 Level taxonomy + snore membership are a single source of truth. Binds classification, metrics, views. Prevents Noise being counted as snore or a view using different thresholds. Rule: LEVELS=[Quiet,Light,Loud,Epic,Noise], SNORE_LEVELS=[Light,Loud,Epic] (Quiet and Noise never count toward timeSnoring); ampToLevel thresholds and the WEIGHT map are the only classifiers; new consumers import them, never redefine.
- (decision) AD-6 Delay-window suppression is capture-time, not post-filtering. Binds CAP-2. Prevents a variant that records during the delay then trims, leaking pre-sleep audio. Rule: no samples are captured during the fall-asleep delay window; timeInBed = end - start - delay; skip-delay collapses the remaining window by setting delay to elapsed; segments only ever cover post-delay capture.
- (decision) AD-7 Persistence namespace + single writer. Binds CAP-4. Prevents scattered localStorage keys or views writing storage directly. Rule: all persistence lives under snorenomore.* (nights array at snorenomore.nights, newest-first; seed guard at snorenomore.seeded); only the App root (saveNight/deleteNight/seed) mutates storage, always mirroring the in-memory nights state; reads tolerate corrupt/absent storage by returning [].
- (decision) AD-8 Unidirectional state; views are pure projections. Binds all UI. Prevents view components holding their own copies of night data or mutating storage. Rule: nights in App is the single source of truth; child views receive data + callbacks as props, never touch localStorage or recompute persisted metrics; ephemeral UI state (selection, search, window, detailId) stays local to the leaf.
- (decision) AD-9 Imperative audio isolated behind refs, outside the render cycle. Binds CAP-2. Prevents the audio graph and rAF loop churning component state or leaking across renders. Rule: AudioContext/stream/analyser and the recording accumulator live in refs driven by a single requestAnimationFrame loop; sampling (1/s) and UI updates (~3/s) are throttled separately; teardown stops tracks and closes the context on stop and on unmount.
- (decision) AD-10 Overlay precedence for full-screen modes. Binds navigation. Prevents the user navigating away from a running night or two overlays fighting. Rule: render precedence is recording(Live) > detailNight(Detail) > tab view; the NavBar renders only when neither overlay is active, so a running capture cannot be abandoned by a tab tap.
- (decision) AD-11 Simulated data must be self-identifying. Binds CAP-2 + demo honesty (C3/BA-4). Prevents synthetic nights masquerading as measured. Rule: synthesized nights carry simulated:true and are surfaced as such in the UI; aggregations may include them but the provenance flag is never dropped from the record.
- (constraint) Hard target: iPhone SE 2023 (375x667) mobile Safari, Add-to-Home-Screen standalone PWA; portrait single-column, centered max-width 430px. No tablet/desktop layout in scope.
- (constraint) No service worker in the shipped build. PWA is installable via manifest.json but CDN assets are not cached; first load requires network and a CDN outage breaks the app.
- (version) Preact 10.24.3 (esm.sh) + preact/hooks 10.24.3; htm 3.1.1 (esm.sh); Tailwind Play CDN (cdn.tailwindcss.com, unversioned latest v3); lucide icons hand-inlined as SVG path strings (no runtime dependency). Ratified from the running, judge-accepted build.
- (assumption) Dependency versions are ratified from the shipped, judge-accepted running build rather than web-verified for upgrade; upgrading deps is out of scope for this retro-spec spine.
- (assumption) Segment tStart/tEnd are 0-based ms from CAPTURE start (not absolute epoch); the absolute clock anchor is night.start + delayMinutes*60000. Confirmed from HourlyGraph and samplesToSegments. Load-bearing for UX-4 spike-time mapping and BA-3 day grouping.
- (assumption) All 8 section-10 backlog items (BA-1/2/3/4, UX-1/2/3/4) are additive selectors or UI over the existing night-record contract; none requires a schema migration. Trends stats and spike inspection read persisted snoreScore/segments; day de-dupe groups on night.start.
- (question) Real all-night capture relies on requestAnimationFrame, which pauses when the screen locks or the app is backgrounded -> sample gaps (absent intervals read as Quiet). Background-survival/wake-lock is UX intent only, not implemented. Top real-path risk; the simulate path sidesteps it.
- (direction) Recommend a service worker caching the shell + pinned CDN assets (or vendoring Preact/htm/Tailwind as local static files) to make first-load resilience and true offline match NFR-7 without adding a build step. Also surface localStorage quota errors instead of the current silent try/catch swallow.
