- (direction) Frozen OUTCOME (north star, verbatim): adult completes nightly closed-loop — (1) start recording <10s after tagging up to 3 remedies + 2 lifestyle factors; (2) stop in morning, immediately see timeline segmented Quiet/Light/Loud/Epic/Noise with spikes, Snore Score 0-10, Time Snoring + %; (3) compare in 7-day Trends selecting any remedy to compare avg Snore Score ON vs OFF
- (capability) CAP-1 Nightly setup & tagging: intent=let user tag up to 3 remedies + 2 factors via searchable multi-select with long-press info, checkmarks and Confirm count, pick a fall-asleep delay, optional soundscape, and start recording; success=recording starts <10s after opening setup with selections captured
- (capability) CAP-2 All-night capture & intensity classification: intent=phone mic records all night, skips the fall-asleep delay window, and classifies audio into Quiet/Light/Loud/Epic/Noise segments with loudness spikes; success=a completed night yields a segmented intensity timeline with spikes and no audio leaving the device
- (capability) CAP-3 Morning quantification & night detail: intent=on stop compute Time in Bed (end-start-delay), Time Snoring (Light+Loud+Epic), Snore % and Snore Score 0-10, and present the segmented timeline, circular score and hourly graph with legend; success=user immediately sees score, Time Snoring + % and the segmented timeline on stop
- (capability) CAP-4 Results history: intent=persist nights locally and list them grouped by month with a mini-timeline, remedy/factor icons and circular score, each opening a detail view; success=past nights appear grouped by month and open to their detail
- (capability) CAP-5 7-day Trends correlation: intent=aggregate the last 7 days and let the user select any tagged remedy to compare average Snore Score with the remedy ON vs OFF; success=selecting a remedy shows ON vs OFF average scores demonstrating whether it helps
- (capability) CAP-6 Compliance & privacy: intent=state 'Not medical advice. For apnea risk see doctor.', keep all audio and data on-device, no diagnosis claims, no real-time anti-snore alarm; success=disclaimer visible and no network/cloud calls for audio or data
- (constraint) Platform: PWA, 100% local in mobile Safari on iPhone SE 2023 (375x667), Add to Home Screen standalone, no backend, runnable with no npm install — static index.html + manifest.json served at http://localhost:8000
- (constraint) Stack: React or Preact single-page app, Tailwind-style utility classes, lucide icons allowed, no external native plugins
- (constraint) Privacy: audio never leaves device, no cloud upload, no PHI in logs/localStorage beyond session data
- (constraint) Compliance: UI states 'Not medical advice. For apnea risk see doctor.'; no diagnosis claims; no real-time anti-snore alarm that wakes the user
- (constraint) Required UI elements: fall-asleep delay picker 5/10/15/20/30m that skips recording during the delay; optional Soundscape toggle; Remedy/Factor multi-select with search + long-press info + checkmarks + Confirm count; Results list grouped by month with mini-timeline + icons + circular score; Detail view with hourly graph + legend + Time in Bed / Time Snoring / BreathFlow upgrade placeholder
